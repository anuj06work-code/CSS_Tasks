# Task 2 - CSS Selectors

## Project Description
This project demonstrates the implementation of different CSS selectors using HTML and CSS.

## Technologies Used
- HTML5
- CSS3

## Concepts Covered
- Element Selectors
- Class Selectors
- ID Selectors
- Descendant Selectors
- Pseudo-class Selectors
- nth-child()
- first-child()
- last-child()

## Project Structure

Task2-CSS-Selectors/
- index.html
- style.css
- README.md

## How to Run
1. Download the project.
2. Open the folder in VS Code.
3. Open index.html in your browser.
4. Make sure style.css is properly linked.
